# ZAI Vision — مساعد ذكي بصير

AI Chat Assistant with Live Screen Recording, Camera Vision & Video Analysis.

## Features
- 🧠 Meta Llama 4 (via Puter.js) — Free, no API key
- 👁️ AI Vision — Live camera analysis
- 🎬 Video Upload — Up to 200MB, multi-frame extraction
- 🎤 Voice Input/Output — Speech recognition + TTS
- 📱 PWA — Installable on mobile
- 💬 Chat History — Saved locally

## Tech
- Puter.js (Meta Llama 4)
- Web Speech API
- MediaDevices API
- Canvas frame extraction
