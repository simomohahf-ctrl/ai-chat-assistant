# ZAI Vision — مساعد ذكي بصير

AI Chat Assistant with Live Screen Recording & Vision capabilities.

## Features
- 🤖 AI Chat powered by Groq Llama 3.3 70B
- 👁️ Live screen capture & analysis (getDisplayMedia)
- 🎤 Voice interaction (Web Speech API)
- 📱 Picture-in-Picture overlay
- 🌍 Full Arabic RTL support
- 📱 PWA installable on mobile

## Tech Stack
- Vanilla JS + CSS + HTML
- Groq API (Llama 3.3 70B)
- Web Speech API (STT + TTS)
- getDisplayMedia (screen capture)
- Service Worker (PWA)

## Live Demo
Deployed on Base44 HTTPS + GitHub Pages.
